# QuickDesk

A real-time bidirectional communication platform built using React, Node.js, Express, and Socket.IO.

## Overview

QuickDesk enables instant communication between connected users using WebSockets. Messages are exchanged in real time without storing chat history in a database, making it lightweight and fast.

---

## Features

- Real-time messaging
- Bidirectional communication
- Low-latency communication using Socket.IO
- Client-server architecture
- Responsive interface
- No database required
- Event-driven communication

## Installation

Clone the repository

```bash
git clone https://github.com/Rishant-Singh/QuickDesk.git
```

Install dependencies

### Server

```bash
cd server
npm install
npm start
```

### Client

```bash
cd client
npm install
npm start
```
